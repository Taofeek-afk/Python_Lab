And the important part

I wouldn't just give you the syllabus and then dump a bunch of explanations on you.

We can make it a guided course. For each lesson, I'd use a pattern like:


Concept → tiny example → line-by-line walkthrough → trace it manually → you predict what happens → we check it → common mistake → exercise → slightly harder exercise

For example, before touching something complicated, we'd get to the point where you can look at:
def countdown(n):
    if n == 0:
        return
    print(n)
    countdown(n - 1)


and confidently explain:

What n is
Why n == 0 matters
What countdown(n - 1) does
Why it doesn't continue forever
What happens to each function call
Why the output is 3 2 1 when starting with countdown(3)
What would break if we changed n - 1
What happens when the function reaches 0
Why return is different from countdown(n - 1)

That mental model is the real goal. Once you understand what's happening underneath, factorial, tree traversal, backtracking, and divide-and-conquer stop looking like completely different topics.
