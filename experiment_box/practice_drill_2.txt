Absolutely. Since you're writing the algorithms yourself instead of relying on Python built-ins, I'd focus on problems that force you to think about **indices, pointers, and boundary conditions**. These skills carry over directly to arrays, strings, linked lists, and even operating systems.

Here's a progression I'd recommend.

### Beginner (Single Index)

These teach you how to traverse correctly.

1. Reverse a string manually (no `[::-1]`).
2. Count vowels and consonants.
3. Remove all spaces from a string.
4. Replace consecutive spaces with a single space.
5. Capitalize the first letter of every word.
6. Check if a string is a palindrome using indices only.
7. Find the longest word in a sentence.

---

### Intermediate (Nested Indices)

These are similar to what you've been doing.

1. Remove duplicate characters **without using a set**.
2. Find the first non-repeated character.
3. Find all duplicate words in a sentence.
4. Count how many times each character appears (without `dict.get()` or `Counter`).
5. Determine whether two strings are anagrams (without sorting).
6. Remove all occurrences of a substring manually.
7. Compress a string:

```
aaabbccccdd
```

↓

```
a3b2c4d2
```

---

### Two-Pointer Problems (Very Important)

These are common in coding interviews.

1. Reverse a list in-place.

```
1 2 3 4 5
```

↓

```
5 4 3 2 1
```

using:

```python
left = 0
right = len(arr) - 1
```

---

2. Check if a string is a palindrome.

```
racecar
```

Compare:

```
left →
← right
```

moving toward the center.

---

3. Move all zeros to the end.

```
1 0 2 0 3 5 0
```

↓

```
1 2 3 5 0 0 0
```

---

4. Remove duplicates from a sorted array.

```
1 1 2 2 2 3 4 4
```

↓

```
1 2 3 4
```

### Sliding Window

Great for learning index arithmetic.

1. Longest substring without repeating characters.
2. Longest sequence of vowels.
3. Find all substrings of length `k`.
4. Maximum sum of `k` consecutive numbers.

## A challenge for you

Based on the questions you've been asking, I think you'd enjoy this one:

> **Implement Python's `split()` exactly.**

Requirements:

* Ignore multiple spaces.
* Ignore leading/trailing spaces.
* Don't use `split()`.
* Don't use regular expressions.
* Use only indices and loops.

Example:

```python
"   Hello    world   from   Python  "
```

should return

```python
["Hello", "world", "from", "Python"]
```

It's deceptively simple, but it teaches careful index handling and edge cases—the same skills you've been building with your duplicate-removal function.

Given your interest in computer architecture, operating systems, and data structures, these kinds of low-level, index-focused exercises will give you a strong foundation before moving on to linked lists, trees, and graphs.
