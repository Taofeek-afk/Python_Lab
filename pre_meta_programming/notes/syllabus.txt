Standard Libraries for Metaprogramming
To master metaprogramming and dynamic code manipulation in Python, you don't need dozens of libraries. You just need to master 5 core standard libraries:

inspect (The Introspection Master):

Lets you look inside live code at runtime. You can extract source code text, inspect function signatures, check parameter types, and trace caller frames.

ast (Abstract Syntax Tree):

Lets you parse Python source code into a syntax tree, modify code structure programmatically (like a compiler), and turn it back into executable code.

types (Dynamic Construction):

Provides low-level utilities to dynamically create new classes (types.new_class), functions, or modules on the fly.

functools (Wrappers & Utilities):

Essential for writing clean decorators using @functools.wraps so your wrapped functions don't lose their original __name__ and docstrings.

importlib (Dynamic Imports):

Allows you to import modules, reload code packages, or load python files dynamically from file paths at runtime (crucial for auto-discovering plugins).
