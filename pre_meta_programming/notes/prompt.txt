Part 1: Replicating Built-in Decorators via Descriptors
To truly understand @property, @staticmethod, and @classmethod, we must write them ourselves. Since we know descriptors control attribute lookup on classes, we can implement Python's exact core behaviors using user-defined classes.

1. Replicating @property (A Custom Data Descriptor)
A built-in property manages a getter, a setter, and a deleter. Because it implements __set__, it acts as a data descriptor, meaning it takes precedence over instance dictionary lookups.

Python
class CustomProperty:
    def __init__(self, fget=None, fset=None, fdel=None):
        self.fget = fget
        self.fset = fset
        self.fdel = fdel

    def __get__(self, instance, owner):
        if instance is None:
            return self  # Accessed on the class, return the property object itself
        if self.fget is None:
            raise AttributeError("unreadable attribute")
        return self.fget(instance)  # Call the getter function, passing the instance as 'self'

    def __set__(self, instance, value):
        if self.fset is None:
            raise AttributeError("can't set attribute")
        self.fset(instance, value)  # Call the setter function

    def __delete__(self, instance):
        if self.fdel is None:
            raise AttributeError("can't delete attribute")
        self.fdel(instance)

    # Optional: Mimicking the .setter method decorator chain
    def setter(self, fset):
        return type(self)(self.fget, fset, self.fdel)


# --- Testing CustomProperty ---
class Person:
    def __init__(self, name):
        self._name = name

    @CustomProperty
    def name(self):
        return self._name

    @name.setter
    def name(self, value):
        if not isinstance(value, str):
            raise TypeError("Name must be a string")
        self._name = value

p = Person("Alice")
print(p.name)       # Triggers CustomProperty.__get__ -> "Alice"
p.name = "Bob"      # Triggers CustomProperty.__set__
print(p.name)       # "Bob"
2. Replicating @staticmethod (A Non-Data Descriptor)
A static method does not care about the instance or the class. Its __get__ method simply returns the underlying function object untouched, completely bypassing any binding logic.

Python
class CustomStaticMethod:
    def __init__(self, func):
        self.func = func

    def __get__(self, instance, owner):
        # Returns the raw function directly whether accessed via instance or class
        return self.func


# --- Testing CustomStaticMethod ---
class MathUtils:
    @CustomStaticMethod
    def add(a, b):
        return a + b

print(MathUtils.add(2, 3))  # 5
print(MathUtils().add(2, 3)) # 5 (No 'self' or 'cls' injected)
3. Replicating @classmethod (A Non-Data Descriptor)
A class method requires the class (owner) to be passed as the first argument instead of the instance. Its descriptor __get__ wraps the function using Python's types.MethodType or a custom closure, binding the function to the class object.

Python
import types

class CustomClassMethod:
    def __init__(self, func):
        self.func = func

    def __get__(self, instance, owner):
        # Bind the function to the 'owner' (the class) instead of the 'instance'
        return types.MethodType(self.func, owner)


# --- Testing CustomClassMethod ---
class Config:
    DEFAULT_ENV = "production"

    @CustomClassMethod
    def get_env(cls):
        return cls.DEFAULT_ENV

print(Config.get_env())  # "production" (Config class passed automatically as cls)
